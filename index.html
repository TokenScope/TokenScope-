How TokenScope Works
TokenScope is designed to bring market, blockchain and security information together so users can investigate tokens more efficiently.

1. Discovery

TokenScope can scan supported data sources and identify tokens that meet configured measurable criteria.

2. Search

Users can search for a token by name, symbol or contract address. A token can still be displayed even when it does not meet the discovery criteria.

3. Analyzer

The Analyzer combines available market, on-chain, holder, liquidity, wallet, security and other relevant information.

4. TokenScope Score

The score is intended to summarize measurable signals. TokenScope should explain the factors contributing to the score rather than hiding the reasoning.

5. Evidence First

TokenScope should present available evidence and risk indicators. It should not label a token a scam without sufficient evidence.
